# CropGuard AI

Build a modern, attractive, mobile-first AI agriculture website called “CropGuard AI” — an AI-powered early-warning system for crop diseases.

Core Feature

Farmers can:

Upload/capture a crop leaf image

Detect possible diseases using AI

See disease name, confidence score, symptoms, and severity

Get basic treatment & prevention suggestions

Save and compare previous scans

Receive weather-based disease-risk alerts

Use the app in regional languages, especially Hindi and English

Main Pages

Home/Dashboard — crop health score, risk level, recent scans, quick actions.

AI Crop Scanner — upload/camera → AI analysis animation → disease result.

Scan Result — disease, confidence %, severity meter, symptoms, recommendations.

My Crops — saved crops, health scores, disease history and trend charts.

Weather Risk — temperature, humidity, rainfall and 7-day disease-risk forecast.

Disease Library — searchable crop diseases, symptoms and prevention.

Scan History — previous images and results with comparison.

AI Assistant — simple chatbot for crop-health questions.

Profile/Settings — language, notifications and saved preferences.

Extra Smart Features

Crop health trend graph

Low-confidence warning when AI is uncertain

Smart alerts for increasing disease risk

Manual State/District/Village selection

Guest mode + login

Expert consultation option

Delete scan/history controls

Support crops such as tomato, wheat, rice, potato, soybean, maize and cotton

UI/UX

Use a premium AgriTech + AI design:

Green, cream and earthy colors

Rounded cards and subtle shadows

Clean typography

Beautiful crop/leaf visuals

AI scanning animation

Smooth micro-interactions

Large, simple buttons

Responsive mobile + desktop design

Make “Scan Your Crop” the primary CTA.

MVP AI

If no real ML model is connected, simulate realistic predictions with demo data, but structure the project so a real image-classification API can later be connected.

Include demo diseases such as:

Tomato Early Blight

Tomato Late Blight

Potato Late Blight

Wheat Rust

Rice Blast

Cotton Leaf Spot

Important Safety/Disclaimer

Clearly display:

“CropGuard AI provides preliminary AI-based guidance and is not a replacement for a qualified agricultural expert. AI predictions may be incorrect. Consult an agricultural professional for serious or uncertain cases.”

Make the final product feel like a real startup/hackathon-ready AgriTech platform, not a basic college website.
